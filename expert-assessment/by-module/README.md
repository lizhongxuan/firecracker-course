## 使用方式

1. 打开要考察的模块，先只读题目，要求候选人说明假设、机制与失败边界。
2. 对照参考答案，选择深入追问，观察条件改变后是否能修正方案。
3. 按每题的核验证据查看源码、时序或本地实验；完成模块末的现场核验。
4. 用同页记录表填写得分与未验证项，再按统一评分表换算岗位分数。

参考答案是一条可行思路，接受论证完整、能验证的其他设计。项目名称、术语和默认参数不作为背诵标准。每题 0–4 分，达到 4 分需要机制、失败、取舍与可核查证据，并能处理条件变化。

建议模块精通判定：全部题目覆盖、每题至少 3 分、至少两题 4 分、现场核验完成，且关键误解已澄清。仅抽问几题或缺少对应证据时记录覆盖范围，不直接推断整体精通。这是本课程的评估规则；生产能力还需真实运行与维护证据支持。
